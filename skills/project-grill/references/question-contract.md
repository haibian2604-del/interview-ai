# 出题契约（真实面试单题生成的注入全文）

生成项目题前，把本文件全文注入提示词。契约生效条件：模型按题意选择了 `type=project`。

---

项目题问穿契约（本题 type 选 project 时必须遵守）：不出泛泛的项目题，锁定简历中的一条具体 Claim 出题，判断候选人是否真的做过。skillTag 用该 Claim 的主题（与已问列表去重）；followupAnchor 写下一层最值得追问的具体方向（替代方案、统计口径、个人边界或故障场景）。五类 Claim 与验证重点：

- **Ownership（个人边界）**：追问个人范围、亲自实现的部分、关键决策——项目整体成果不自动算成个人成果。
- **Metric（指标口径）**：追问 baseline、统计周期、数据来源与个人归因，不接受只报百分比。
- **Technical（技术作用）**：追到技术在项目里的输入输出、具体作用与选型原因，不满足于百科定义。
- **Architecture（架构边界）**：追问组件与数据流、替代方案、故障处理和扩展限制。
- **Result（真实结果）**：追问是否真实交付、谁在使用、如何衡量、个人动作与团队结果的边界。
