# 面镜 Mirror v1 — UX/UI 设计 Brief（shape 产出，待确认）

> 产出方式：impeccable `shape` 流程。视觉世界经概念发牌 + 挑战者融合裁决 + 决策页由用户选定。
> 依据：PRODUCT.md + 用户确认的三项 UX 决策（结构陪练型 / 桌面优先 / 全部 6 页）。

## 1. 任务与受众

中国互联网/泛技术岗求职者，在电脑前用 20-40 分钟认真练一场模拟面试，练完立刻想知道「差在哪、怎么改」。访客模式全部为 **Operate**（完成任务）；表达永不遮蔽任务、状态与熟悉动作。

## 2. 选定视觉方向：考官评分簿（Examiner's Rubric）

**核心命题**：整站是一册面试官的评分工作簿——用户在「作答」，面试官在「批改」，系统在「记录」。评分是产品的灵魂，界面就是评分表本身。

**ONE WORLD 规则（三色油墨纪律，从裁决中继承的强化线，全部计入本方向）**：

- **黑印刷**（#21201d 近黑，纸白 #fbfaf7 地面，#8a8a84 铅印灰）：结构、正文、表格线——一切「印刷」的部分
- **红批改**（#a63a2f）：只在评估/批改时刻出现（分数、批注、雷达图），绝不作装饰性 accent 撒放
- **蓝作答**（#2b4acb）：只属于用户的输入与「进行中」状态（答题区光标、当前题目标记）
- 任何 UI 状态不得引入第四种墨色；成功/错误用印刷语义（印章/勾叉）表达，不用彩色 toast

**材质**：细表格线（1px hairline）、复写纸分数框、rubric 栏目、印章式结果标记、纸面留白遵循印刷边距节奏（上松下紧）。字体：正文与表格用系统黑体栈（中文 UI 工字当头），标题用宋体点出「印刷品」气质；数字一律等宽表格数字。

**动效纪律**（from 夜航仪表，competitive 挑战者）：所有批改类动效必须阻尼、物理化——分数印章缓入、红笔下划书写式出现、雷达图指针阻尼转动；评分先展示与目标的偏差（差什么）再展示数值。

**编号化目录**（from 厂牌目录）：一切皆编号——第 001 场、题 X/Y、卷号；目录即地图，页眉像卷首一样携带编号。

**防校准红线**：这不是「米色纸 + 衬线 + 复古」的文青世界——是**印刷表格**的锐利与工整；纸白必须近白，红必须克制，表格线必须真实承担结构（不是装饰边框）。

## 3. 各页 UX 决策（6 页总图）

**登录 `/login`（Persuade，唯一例外页）**：一册摊开的评分簿封面——左侧产品名「面镜 Mirror」+ 一句话（照镜子式演练：面试是自我认知的镜子），右侧登录表单（魔法链接为主、GitHub 为辅）。品牌在此页可以最有表现力，但仍是同一册纸。

**Dashboard `/dashboard`**：评分簿的**目录页**。每场面试一行目录条目（编号、岗位、题型、状态章、总分章），状态用印章语言（进行中=蓝、已完成=黑、已放弃=灰章）；空态是「尚未开卷」+ 一支笔的引导。顶部导航 = 卷首（产品名 + 简历库入口 + 新建按钮）。

**简历库 `/resumes`**：**一卷一卡**的档案索引（from 球鞋墙的保留线）：每份简历一张实体卡片（卷号、上传日期、结构化画像摘要可展开），不是无形数据行；上传 = 「新建档案」，粘贴文本是平等的次入口。

**创建面试 `/interview/new`**：**填写考卷的「考前登记表」**——分步感的一页表单：选简历（从档案卡中选）→ 岗位与 JD（贴上去）→ 题型与题量（勾选框，默认 6 题）。提交后进入 10-30 秒出题等待：页面切换为「考官正在出卷」的印刷过程反馈（逐条浮现的题目钩稽线），不是干转的 spinner——这是本页最关键的状态设计。

**面试现场 `/interview/[id]`（核心页，结构陪练型）**：
- 布局：左栏（固定）= 答题卡式题号方格导航（已答填墨、进行中呼吸、未答空格）+ 当前题的考察点标签；主区 = 题干（黑体大字，像考卷题干）+ 下方作答流；底部 = 大输入区（作答蓝焦点态，Enter 发送 / Shift+Enter 换行）
- 打字机流式输出 = 面试官的笔迹；候选人消息 = 蓝墨作答
- 追问：面试官消息出现在同一题的作答流内，带「追问」标记（题号方格出现小钩）
- 每题答完：本行即时批改——分数框盖章式出现四维分（阻尼动效），这是「评分簿」身份的核心瞬间
- 中断恢复：刷新后卷面原样还原（每轮落盘是产品承诺，UI 必须兑现它）
- 「放弃面试」= 灰章「缺考」，需二次确认
- 完成瞬间：卷面合卷动画 + 「阅卷完成」→ 跳报告页

**报告 `/report/[id]`（Operate + Read）**：**阅卷完成的试卷与评语册**——顶部总分（大号印章式数字，缓入）+ 四维雷达（阻尼指针转动，先偏差后数值：每维先显示「与目标差距」一句再显示分值）；主体逐题批注卡（题目、四维分框、红笔批注式的亮点与不足——严格考官人格，但不打击：每条不足必须带具体改法）；底部教练评语三段（总结/优势/改进）。语言必须教练式可执行，禁止「加强深度」式空话。

## 4. 范围与边界

- 保真度：production-ready；桌面优先（1440 基准），移动端可用性降级方案：面试现场页左栏折叠为顶部进度条，其余页面单列化——不为移动牺牲桌面
- 反目标（polish 后仍会觉得错的）：聊天气泡圆角卡片风、彩色渐变、emoji 装饰、游戏化元素（连击/积分）、第四种墨色、拟真倒计时压迫感
- 不触碰：五 Agent 架构、状态机规则（阈值 0.65）、RLS、已定接口签名

## 5. 状态与区间清单

出题中（10-30s 印刷反馈）｜面试中断恢复｜追问轮｜放弃确认｜空态（无简历/无面试/无报告）｜错误态（LLM 失败 502、PDF 是扫描件）｜流式断流｜报告幂等（重复生成不重复写）｜题数 3-10 区间
